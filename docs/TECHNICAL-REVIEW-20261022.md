This record separates evidence types. It does not promise universal absence of
defects, independent cultural quality or unlimited provider capacity.

## Local source and interface

The Gemini presentation candidate passed 801 Windows unit tests, type checking,
production export, source-package checks and 19 isolated desktop/mobile browser
groups. Those browser groups used labelled synthetic providers. The public
Windows/Linux checks for the published commit are a separate observation in
[GitHub Actions](https://github.com/seypherWork/affinityqa/actions/workflows/public-source-tests.yml).

The original recorded capture was verified read-only against that runtime:
54 replays passed, including 18 controlled context comparisons. All 384 original
files retained their hashes. There were zero new Qloo or Groq calls. A manual
interface walkthrough also passed all three supported incidents, their eight
evidence checks and six recovery controls; the wrong-tool-context comparison
passed its thirteen controls.

## Real-provider trials

The first local trial used Daft Punk, a confirmed known favorite Tron: Legacy
(2010), and an explicitly synthetic science-fiction direction. Qloo retrieved
100 candidates and the model delivered five films. Four Qloo requests and one
Groq selection completed. The UI's film identities, order, source descriptions
and five original illustrations matched the native result.

Its automated download check failed; the exact cause was not established.
The temporary browser context was then closed, so that trial's cookie could
not legitimately be recovered. The case and failed test record were preserved.
This trial's download/restoration is **NOT ACCEPTED**. It is not counted as a
completed human test or a complete download walkthrough.

The second local trial, Scary Movie (2000), passed identity confirmation,
five results, source-bound descriptions, all five original illustrations,
physical verification download and session restoration. Both downloaded
verification files had the same SHA-256. It used three Qloo requests and one
Groq selection, with explicitly synthetic parody/horror-comedy preferences.
The supervisor closed cooperatively: cumulative local usage was seven Qloo
requests and two Groq selections, with no failed/unknown sends or queued jobs.
The first retained Daft case, source and original captured evidence remained
unchanged. This does not change the earlier Daft download test's outcome.

Subsequent local/hosted acceptance must be checked separately before declaring
the jury route ready. Updated hosted verification belongs to the exact
deployed revision and is reported in the existing
[Devpost presentation](https://devpost.com/software/affinityqa), rather than
attributed to this earlier partial UI trial.
